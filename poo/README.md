# POO

Os fundamentos que sustentam todo o resto do curso: [SOLID](../solid/README.md) são princípios sobre objetos, [DESIGN PATTERNS](../design-patterns-em-oo/README.md) são soluções montadas com objetos, e [CLEAN ARCHITECTURE](../clean-architecture/README.md) é a organização desses objetos em camadas.

- [CONCEITOS DE POO](conceitos-de-poo.md) — classe e objeto, memória, os quatro pilares com código, sobrecarga × sobrescrita, classe abstrata × interface, herança × composição, acoplamento e coesão, `equals`/`hashCode`, imutabilidade e Java moderno (records, sealed, pattern matching)
- [MANIPULAÇÕES E EXCEÇÕES](manipulacoes-e-excecoes.md) — Call Stack, hierarquia de `Throwable`, checked × unchecked, `try-catch-finally`, try-with-resources, exceções customizadas, encadeamento e anti-padrões

**Relacionados:** [SOLID](../solid/README.md) · [DESIGN PATTERNS EM OO](../design-patterns-em-oo/README.md) · [CLEAN ARCHITECTURE](../clean-architecture/README.md)
